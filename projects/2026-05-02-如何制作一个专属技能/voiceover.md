# 三分钟制作专属技能 — 口播文案

> 总字数: 304字 | 预估时长: 1分08秒

---

你知道吗？Claude Code 里有一个功能，能让 AI 自动记住你的工作流程，每次都按你的方式干活。

很多人每天都在重复做同样的事——写同样的提示词，走同样的流程。其实只需要三分钟，就能把这些全部自动化。

第一步，先别急着动手。想想你每天最常重复的工作是什么？然后去搜一下，有没有人已经做好了。GitHub 上有大量现成的技能，可以直接安装使用。

找不到现成的？那就自己做一个。Claude Code 自带了 skill-creator 命令，你只需要告诉它你想要什么，它就能帮你生成完整的技能。

记住三个原则。第一，别做大而全，拆成小技能，每个只做一件事。第二，密钥不要写死，用环境变量。第三，技能需要迭代，用着不对就让 AI 调整。

什么时候用技能，什么时候写代码？如果你需要跟 AI 反复沟通、动态调整行为，用技能。如果追求百分百准确、或者需要可视化界面，写代码。

三分钟，把重复工作变成专属技能。关注我，每天一个 AI 实用技巧。
